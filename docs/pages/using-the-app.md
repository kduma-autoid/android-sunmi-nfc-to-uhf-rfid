# Using the app

The bottom navigation has four tabs — **About**, **Encode**, **Scan**, **Validate** —
plus a settings gear in the top bar.

The About tab shows the app version, the detected UHF reader model and a summary of
the encoding format.

## The workflows

- [Encoding a tag](encoding) — copy a card's UID onto a UHF tag (Encode tab).
- [Bulk inventory and validation](scanning) — continuous inventory with live pairing
  checks (Scan tab).
- [One-by-one validation](validating) — instant PAIRED / TAG MISSING verdict per card
  (Validate tab).
- [Settings](settings) — passwords, locking, scan duration and radio power.
