# Installation

On a Sunmi device, install the app from the **Sunmi App Store** — open this link on
the device:

```
market://woyou.market/appDetail?packageName=dev.duma.android.nfctorfid
```

Alternatively, download the APK from the project's
[GitHub Releases](https://github.com/kduma-autoid/android-sunmi-nfc-to-uhf-rfid/releases)
page or build from source (see [Development](development)).
